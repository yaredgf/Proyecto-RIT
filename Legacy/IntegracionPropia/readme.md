# Arañador propio del Proyecto I

Implementación archivada con Requests y Beautiful Soup. Usa la configuración compartida del repositorio, lee `enlacesBuscados.json` y guarda sus resultados junto a `app.py`.

Para ejecutarlo con esas dependencias instaladas, use `python Legacy/IntegracionPropia/app.py` desde la raíz. El código crea los directorios de salida `Pruebas/` y `Texto/` al iniciar.
